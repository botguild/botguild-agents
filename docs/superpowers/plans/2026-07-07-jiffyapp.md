# JiffyApp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the JiffyApp bot per `docs/prds/jiffyapp.md` + `docs/prds/jiffyapp-templates.md`: two Cloudflare Workers (`apps/jiffyapp-bot`, `apps/jiffyapp-dispatch`) that turn a one-paragraph gig brief into a deployed micro-tool on `<slug>.jiffyapp.dev`, gated by buyer-approved golden Playwright assertions, with $5/mo hosting cycles and bounded edits.

**Architecture:** `jiffyapp-bot` is a marketplace bot on the proven `@botguild/agent-core-workers` shim (Hono fetch + Queue consumer + 2 crons): it discovers gigs, compiles golden input→output examples into the proposal (acceptance = sign-off), and on funding runs moderate → codegen (Workers AI Qwen slot-filling into a bounded 10-template catalog) → staging deploy (Workers-for-Platforms dispatch namespace via Cloudflare REST API) → Playwright golden assertions (Browser Rendering) with a capped self-repair loop → promote → live gates (200 + element census + goldens re-run + PSI Lighthouse) → evidence report + eject ZIP → `deliverMilestone`. `jiffyapp-dispatch` is a tiny router on `*.jiffyapp.dev`: hostname → slug → D1 status → `env.DISPATCH.get(slug)`, 410 for suspended tools. Templates are code, not data: each declares slots (the only thing codegen writes), a `data-testid` element contract (the only thing goldens may bind), and a deterministic `render()`.

**Tech Stack:** TypeScript (NodeNext), Hono, `@botguild/agent-core` + `@botguild/agent-core-workers` (unmodified), `@botguild/sdk` ^0.3.0, `@anthropic-ai/sdk` ^0.51.0 (Haiku: goldens compiler, cover notes, escalation round), Workers AI (`AI` binding, Qwen2.5-Coder-32B), Browser Rendering + `@cloudflare/playwright` (exact-pinned), Workers for Platforms (`DISPATCH` binding + REST script PUTs), D1/KV/R2/Queues, Cloudflare Email Service (`SEND_EMAIL` binding + `mimetext`), PageSpeed Insights API, OpenAI Moderation (pinned `omni-moderation-2024-09-26`), `fflate` (eject ZIP), node:test via tsx (NO vitest, NO miniflare).

## Global Constraints

Copied from the PRDs and the fleet conventions; every task's requirements implicitly include these.

- **Node ≥22, pnpm 9.15.0, Turborepo.** New apps are picked up by root `pnpm build/typecheck/test/lint` automatically; do NOT add docker-compose or docker-build CI entries (Workers apps deploy via wrangler, not Fly).
- **Tests are `node:test` via `tsx --test`** (script: `"test": "tsx --test src/*.test.ts src/**/*.test.ts"`). No vitest, no miniflare. Workers bindings are consumed through structural interfaces (`D1Like`, `KVLike` from the shim; new `AiLike`, `BrowserLauncher`, `DispatchLike`, `RelayMailer`, `QueueLike` defined in this app) so every module except `src/index.ts` is Node-testable. `src/index.ts` is the ONLY module that touches real bindings.
- **`module: NodeNext`** — all relative imports carry `.js` extensions (`import { x } from './config.js'`).
- **tsconfig per app** extends `../../tsconfig.base.json` with `"types": ["@cloudflare/workers-types", "node"]`, `rootDir: ./src`, `outDir: ./dist`, references to `../../packages/agent-core` and `../../packages/agent-core-workers` (dispatch app: no references).
- **Package naming:** `@botguild/jiffyapp-bot`, `@botguild/jiffyapp-dispatch`, `"private": true`, `"version": "0.1.0"`, `"type": "module"`. Workspace deps as `"workspace:*"`. Caret pins by default; **exact pins only where a runtime invariant demands it** (`@cloudflare/playwright` — the fleet's playwright image-pairing lesson, PR #72).
- **Zero shim modifications** (PRD §15 success metric) and zero `agent-core` modifications. The golden-examples proposal block is added by *wrapping* `createProposer`, never by editing it.
- **`compatibility_date: "2026-06-01"`**, `"$schema": "node_modules/wrangler/config-schema.json"`, placeholder ids marked `⚠️ REPLACE`, `observability: { enabled: true }` in every wrangler.jsonc. `compatibility_flags: ["nodejs_compat"]` on the **bot** Worker only (required by agent-core's Buffer use); the dispatch Worker uses no Node APIs and omits it.
- **The platform webhook signing secret lives in D1** (captured by `ensureRegisteredWorkers` with awaited write + read-back), never in wrangler secrets.
- **Never expose recomputable keys:** `jobKey = sha256(contractId) + ':' + stage` is an idempotency key only. Everything publicly reachable — deliverables URLs, the build-log page, AND the staging slug — derives from the per-job random 64-hex `deliverable_token` (VoiceWright migration-0002 lesson).
- **Webhooks are handler-scoped:** every contract-scoped handler self-filters with `isOwnContract` (via `withOwnershipFilter` or an inline `getContract` + check). The `milestone.funded` payload has NO `milestoneId` — deliver by fetching the contract and finding its `status === 'funded'` milestone.
- **KV is advisory only** (poller seen-ids). All correctness state (claims, caps, quotas, counters) is D1 with unique-constraint INSERT / conditional-UPDATE atomicity.
- **Moderation fails closed:** pinned vendor `openai` / model `omni-moderation-2024-09-26`; outage ⇒ `park(jobKey, 'moderation_outage')` + cron re-enqueue, thread notice after 3 attempts. Never skipped, never a pass on error.
- **Hard caps (FR-6):** ≤3 repair rounds, ≤$0.50 model spend, ≤25 min **active work time** per job. Active time = time actually spent in consumer invocations, accumulated as `checkpoint.activeMs` and persisted per checkpoint — NEVER wall-clock since funding: parked waits (moderation outage, brief corrections, relay verification) do not consume the cap. Cap state lives in the D1 checkpoint so queue retries resume, never restart. Non-convergence ⇒ abort leg: deliver nothing, tear down staging, post failing evidence (screenshots) to the thread, **request** payer cancellation (bot-side refund does not exist).
- **Numeric defaults are provisional until Phase 2 calibration** (PRD §9): PSI performance ≥90 / accessibility ≥90 (a11y is Foreman's parent gate — least negotiable), per-assertion timeout 5000 ms, relay caps 5/min + 100/day per tool, edit quota 3/cycle, grace 7 days, relay metadata retention 30 days, stuck-claim sweep 30 min, queue `max_batch_size: 1`, `max_retries: 3` + DLQ.
- **Template catalog is the scope boundary** (templates PRD §1): no build step at job time, vendored pinned deps only, strict CSP (self + bot origin for relay only), no cookies/storage/third-party origins, stateless tools (relay is the only side effect), "Built by JiffyApp" footer + report-abuse link on every page, codegen writes only slot values.
- **Golden vocabulary** (templates PRD §1.4) is the ONLY assertion language: actions `load, fill, select, click, paste, upload`; expectations `equals, contains, count, visible, hidden, hrefEquals, hrefStartsWith, attrEquals, titleEquals, metaEquals`, optional `nth`. No regex, no screenshots-as-oracle (screenshots are evidence, never the check).
- **Prices:** landing $15, calculator $25, form $15, csv-dashboard $25, widget $5, link-in-bio $10, pricing-table $15, quiz $25, waitlist $10, transformer $15; hosting $5/mo. Bid price = `max(1.5 × estimated cost, gig.budget)` via `createCostEstimator`; negotiation floor = the estimator `target`.
- **Deliverable links are Worker-served** (`/deliverables/:token/:file`), never `r2.dev`.
- **Branch/commits:** work on branch `jiffyapp` cut from `thumbforge-voicewright`. Conventional commits (`feat(jiffyapp): …`), one commit per task, ending with `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- **Run tests as:** `pnpm -w build && cd apps/jiffyapp-bot && pnpm test` (turbo `test` depends on `^build`; workspace imports resolve to `dist/`). After edits to `packages/*` (never needed here) rebuild first.
- **Out of code scope (ops, documented in README only):** registering `jiffyapp.dev`, activating Workers for Platforms + creating the namespace, issuing the scoped `CF_API_TOKEN`, PSI key, Email Service sender domain (SPF/DKIM), listing seed gigs, and the Phase-2 live calibration numbers.

// Pure routing policy for *.jiffyapp.dev. No bindings — fully node-testable.

export type DispatchDecision = { kind: 'serve' } | { kind: 'gone' } | { kind: 'unknown' };

/** One label directly under the suffix, else null (apex, www, nested, foreign hosts). */
export function resolveSlug(hostname: string, hostSuffix: string): string | null {
  const host = hostname.toLowerCase();
  const suffix = `.${hostSuffix.toLowerCase()}`;
  if (!host.endsWith(suffix)) return null;
  const label = host.slice(0, -suffix.length);
  if (label === '' || label === 'www' || label.includes('.')) return null;
  return label;
}

/** tools.status → routing outcome. live|grace serve; suspended|killed are 410; anything else 404. */
export function decideDispatch(status: string | null): DispatchDecision {
  if (status === 'live' || status === 'grace') return { kind: 'serve' };
  if (status === 'suspended' || status === 'killed') return { kind: 'gone' };
  return { kind: 'unknown' };
}

export const GONE_PAGE_HTML = `<!doctype html><html lang="en"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1"><title>Tool suspended — JiffyApp</title>
<style>body{font-family:system-ui,sans-serif;max-width:38rem;margin:4rem auto;padding:0 1rem;color:#222}</style></head>
<body><h1>410 — this tool is suspended</h1>
<p>Hosting for this tool has lapsed. It is served while a monthly hosting gig is funded, with a 7-day grace period.</p>
<p><strong>Owner?</strong> Fund a new $5/mo JiffyApp hosting gig referencing your toolId to revive this URL,
or use the eject ZIP from your delivery to self-host — the source is yours.</p>
<p>Built by <a href="https://jiffyapp.dev">JiffyApp</a>.</p></body></html>`;

<title>Not found — JiffyApp</title></head><body><h1>404 — no tool here</h1>
<p>Built by <a href="https://jiffyapp.dev">JiffyApp</a>.</p></body></html>`;

`apps/jiffyapp-dispatch/src/index.ts`:

```ts
import { resolveSlug, decideDispatch, GONE_PAGE_HTML, NOT_FOUND_PAGE_HTML } from './decide.js';

export interface Env {
  DB: D1Database;
  DISPATCH: DispatchNamespace;
  TOOL_HOST_SUFFIX: string;
}

const html = (body: string, status: number) =>
  new Response(body, { status, headers: { 'content-type': 'text/html; charset=utf-8' } });

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const slug = resolveSlug(new URL(request.url).hostname, env.TOOL_HOST_SUFFIX);
    if (!slug) return html(NOT_FOUND_PAGE_HTML, 404);

    const row = await env.DB.prepare('SELECT status FROM tools WHERE slug = ?')
      .bind(slug)
      .first<{ status: string }>();
    const decision = decideDispatch(row?.status ?? null);
    if (decision.kind === 'gone') return html(GONE_PAGE_HTML, 410);
    if (decision.kind === 'unknown') return html(NOT_FOUND_PAGE_HTML, 404);

    try {
      return await env.DISPATCH.get(slug).fetch(request);
    } catch {
      // Script missing despite a serving status (deploy race) — honest 404, never a 500 loop.
      return html(NOT_FOUND_PAGE_HTML, 404);
    }
  },
};
```

// Node-only test helper: replays migrations/*.sql into an in-memory D1 so tests
// exercise the exact schema `wrangler d1 migrations apply` produces.
import { readdirSync, readFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import type { D1Like } from '@botguild/agent-core-workers';

const MIGRATIONS_DIR = join(dirname(fileURLToPath(import.meta.url)), '..', 'migrations');

export async function applyMigrations(db: D1Like): Promise<void> {
  const files = readdirSync(MIGRATIONS_DIR).filter((f) => f.endsWith('.sql')).sort();
  for (const file of files) {
    const sql = readFileSync(join(MIGRATIONS_DIR, file), 'utf8');
    const statements = sql
      .split(/;\s*\n/)
      .map((s) => s.split('\n').filter((line) => !line.trim().startsWith('--')).join('\n').trim())
      .filter((s) => s.length > 0);
    for (const statement of statements) {
      await db.prepare(statement).run();
    }
  }
}

```ts
export function buildToolWorkerScript(files: FileSet, csp: string): string {
  const sorted = Object.fromEntries(Object.entries(files).sort(([a], [b]) => a.localeCompare(b)));
  return `// Generated by JiffyApp — do not edit in place; see the eject ZIP README.
const FILES = ${JSON.stringify(sorted)};
const CSP = ${JSON.stringify(csp)};
function bytes(entry) {
  if (entry.encoding === 'base64') {
    const bin = atob(entry.content);
    const out = new Uint8Array(bin.length);
    for (let i = 0; i < bin.length; i++) out[i] = bin.charCodeAt(i);
    return out;
  }
  return entry.content;
}
export default {
  async fetch(request) {
    const url = new URL(request.url);
    let path = url.pathname;
    if (path === '/' || path === '') path = '/index.html';
    const entry = FILES[path];
    if (!entry) return new Response('not found', { status: 404 });
    const headers = {
      'content-type': entry.contentType,
      'x-content-type-options': 'nosniff',
      'referrer-policy': 'no-referrer',
    };
    if (entry.contentType.startsWith('text/html')) headers['content-security-policy'] = CSP;
    return new Response(bytes(entry), { headers });
  },
};
`;
}
```
